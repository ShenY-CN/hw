# 论文图表生成

本目录只放绘图代码。每次生成的一组 PDF、PNG、SVG 都写入项目根目录 `figures/` 下独立子文件夹，并同步生成同目录的 `图组清单.md`；各脚本读取 `results/` 中已计算并核验的 JSON，不在绘图阶段重新求解。

地图底图使用 `input/镇龙乡及周边30米DEM.tif`；GeoTIFF 为 EPSG:4326，像元分辨率约为 30 米。道路、水系、水体面及村镇点位取自 `input/镇龙乡地理空间数据/镇龙乡及周边地理数据/` 下的 CSV，经纬度统一换算为以 O01 为原点的局部公里坐标后再叠加，避免经纬度与局部航线坐标直接混画。

## 分题入口

| 脚本 | 输出图表 | 主要数据来源 |
|---|---|---|
| `q1.py` | 镇龙乡 30 米 DEM、道路/水系/水体/村镇点位、调度中心和服务区；最大安全载荷散点图/热力图、典型航线地形剖面、最远服务区载荷—能耗曲线、时间/能耗单目标方案、安全余量敏感性、返航 SOC | WGS84 CSV/TIFF 图层、`q1_rho*.json`、`q1_energy.json`、`q1_time.json`、共享 `Model` |
| `q2.py` | 叠加地理图层的运输路线、无人机甘特图、电池任务/充电时间线、逐箱送达时限、返航 SOC、搜索候选比较、架次能耗 | `q2.json`、`method_comparison.json`、镇龙乡空间 CSV、共享 `Model` |
| `q3.py` | 叠加地理图层的中继布设地图、直连盲区的中继覆盖采样图、通信提供方时间轴、链路裕量分布、运输/中继联合甘特图、中继 SOC、Q2/Q3 指标比较 | `q2.json`、`q3.json`、镇龙乡空间 CSV、共享 `Model` |
| `q4.py` | 叠加地理图层的2组/3组分区地图、资源需求与库存、组间工作量、库存缺口、任务关联网络 | `q3.json`、`q4.json`、镇龙乡空间 CSV、共享 `Model` |
| `spatial.py` | DEM 和 B 型机单程参考时间六边形图、两组/三组分区对照、标准差椭圆、三维地形航线、分时航线地图 | `q2.json`、`q3.json`、`q4.json`、DEM、共享 `Model` |
| `overview.py` | 把可编辑的总体技术路线图 `figures/fig_roadmap.drawio` 渲染为 PDF、PNG、SVG | DrawIO 源图 |

生成全部配图时使用：

```bash
.venv/bin/python code/mountain_flood/figure/generate.py
```

可使用 `--name 20260925_revision` 指定图组子文件夹名；省略时自动用精确到微秒的时间命名。单独运行 `q2.py` 等脚本也会建立自己的图组子文件夹；如需把几个脚本的输出合并到同一组，先设置环境变量 `MOUNTAIN_FLOOD_FIGURE_SET` 为同一个名称。

完整复现入口会依次运行四个分题脚本、空间图脚本和总体路线图渲染脚本，统一写入 `figures/reproduced_figures/`。`common.py` 集中管理输出路径、字体、配色、DEM 空间底图及面板对齐检查，避免各题重复维护地图口径。全部图采用同一机型色系：A 型蓝、B 型橙、C 型红；地形使用蓝—浅黄—赭红连续色阶。

六边形参考时间基于真实 DEM、O01 坐标和 B 型机飞行参数，计算格心单程时间。任务分组的彩色服务点来自 `q4.json`；六边形描边仅按最近服务点推断视觉分界，不能解释为优化模型求得的连续行政边界。标准差椭圆按每组服务点等权计算，单点组只标中心。

《图表安排参考.md》中的算法流程、通信原理等概念示意图不由这四个数据图脚本推算；总体技术路线仍以可编辑 DrawIO 源图维护。尚无对应原始数据或结果字段的建议图，不从缺失数据中编造数值。
