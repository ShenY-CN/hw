# 山区洪涝无人机救援建模

本项目研究山区洪涝后的无人机物资投送、通信中继和分区资源配置。80 个货箱都必须送到原始服务区，并在各自截止时间前完成交接；逾期或错站均视为不可行。方案在通过硬约束后，再比较全部设备返航时间、优先加权交付时间、能耗和架次数。

## 当前结果

| 问题 | 当前方案 | 关键说明 |
|---|---|---|
| 一 | 20% 返航储备下 18 架次、59.1313 kWh | 给定单点组批模型内的动态规划结果 |
| 二 | 24 架次；全部设备 104.61 min 返航；加权平均交付 45.69 min；71.9169 kWh | 80 箱按时；四种算法同预算比较，局部爬山种子 1 入选 |
| 三 | 26 个运输、3 个中继架次；112.82 min 全部返航；78.8732 kWh | 80 箱按时；4061 个通信区间通过连续链路校验 |
| 四 | 两组或三组独立执行均需补充资源 | 按第三问固定任务做组件分区穷举 |

问题二比较随机化构造、局部爬山、模拟退火和禁忌搜索，每种方法使用 3 个种子；各方法共享同一运输物理模型、排程器、硬约束和验证器。当前入选方案是本次有限搜索候选中的相对最优，不能解释为全局最优。详情见 [结果报告](reports/RESULTS_REPORT.md) 和 [验收报告](reports/VERIFY_REPORT.md)。

公开仓库仅作为算法比较与组批思路参考。对可取得的逐箱路线逐项核验后，发现部分归档方案存在交付服务区不一致；审计范围和结果见 [公开项目核对报告](reports/PUBLIC_REPOSITORY_AUDIT.md)。

## 复现与交付文件

使用 Python 3.12 和锁定依赖，在项目根目录执行：

    python code/reproduce.py --output /path/to/new-empty-output

输出目录须不存在。复现入口重算问题一，对归档方案独立核验，并生成提交表、图表和复现清单。四算法搜索结果保存在 `results/method_comparison.json`；固定随机种子和时间预算的搜索过程，与确定性归档回放分开记录。

- `D题论文.pdf`：交付论文；`paper/main.tex` 及 `paper/sections/`：论文源文件。
- `D题结果提交表.xlsx`：逐问结果与逐箱交付明细。
- `reports/`：模型分析、结果、验收及公开仓库审计。
- `results/`：方案数据、逐箱时刻、验证与复现记录。
- `figures/`：结果图和可编辑技术路线图。

附件未提供排放因子，结果报告飞行耗电，不据此推算碳减排。论文封面身份信息以及模型、代码和结果仍需参赛队独立复核。
